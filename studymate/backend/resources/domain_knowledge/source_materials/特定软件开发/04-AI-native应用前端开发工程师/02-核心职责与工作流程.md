# AI-native 应用前端开发工程师 - 02 核心职责与工作流程

**职责 1：流式 AI 交互。**实现增量消息、停止、取消、错误和完成状态，并将模型事件转换为稳定的页面状态。 [S1][S2]

**职责 2：Agent 与工具交互。**展示工具调用、确认步骤、执行阶段、日志和人工重试，使协同过程可观察而非只显示加载动画。 [G1][G2]

**职责 3：RAG 与来源展示。**呈现来源标题、版本/页码、引用展开、检索为空和权限失败；前端不应掩盖回答缺乏证据的状态。 [S3][S4]

**职责 4：性能与端侧能力。**对大文件解析、长会话和端侧推理评估 Worker、缓存、虚拟化和 WebGPU 方案。 [G3][G4]

**职责 5：质量、安全和无障碍。**保护密钥、验证用户输入和安全渲染生成内容；为动态状态提供键盘、焦点和屏幕阅读器支持。 [S4][S5][S6]

## 标准工作流程

**步骤 1：**明确用户任务、事件协议、引用字段、工具确认点、失败语义、权限和监控指标。 [S1][S3]

**步骤 2：**封装流式客户端、会话状态、引用卡片、错误边界和取消/重试组件。 [S1][S2]

**步骤 3：**完成业务页面和后端联调，验证模型输出、文件上传、来源跳转、断网和异常降级。 [S3][S4]

**步骤 4：**对目标浏览器执行长会话、弱网、并发交互、键盘流程和无障碍验证。 [S5][G5]

**步骤 5：**上线后采集错误、性能与交互反馈，修正状态、组件和降级路径。 [G5][G6]

## 交付物与建议考核

交付物可包括事件协议文档、AI 组件、流式 Hook、状态图、RAG/Agent 页面、无障碍报告、单元/E2E 测试、性能记录与监控配置。 [G1][G5][G6]

建议记录流式失败率、取消成功率、断线恢复率、任务完成率、引用点击率、无障碍检查和前端错误；具体性能阈值须由目标设备与服务 SLA 确定。 [S5][G6][G7]

## 国内招聘证据对应

四川智服人力资源有限公司的“AI 前端开发工程师”直接提及大模型对话平台、AI 智能助手、AI Agent 与 RAG 知识库的前端研发，是本文 AI-native 交互职责的国内岗位样本。[J1]

J2-J7 均为可直达的前端或 Web 前端职位详情页。它们只用于支持 AI 前端所需的通用 Web 工程基础，如前端研发与页面交付；流式协议、Agent 状态和 RAG 引用等 AI 专属技术结论仍须以对应的 SDK、标准和开源源码为准。[J2][J3][J4][J5][J6][J7][S1][S2][S3]

## 职责卡与验收

|职责|输入/动作|输出/验收|
|---|---|---|
|流式交互|SSE/响应流、取消信号、chunk 协议|增量消息、停止/重连与错误状态；弱网不重复拼接。[S2][S6]|
|Agent 状态|会话、节点、工具调用事件|状态图与可解释日志；并发会话互不污染。[G1][G2]|
|RAG 界面|文档、引用与权限结果|分片进度、来源跳转、无证据和越权提示。[S3][S4]|
|端侧推理|模型清单、WebGPU 能力、缓存空间|Worker、进度、内存失败降级。[G3][G4]|
|质量治理|用户流程、恶意输出、键盘/读屏|E2E、无障碍、安全渲染和监控报告。[S4][S5][G5][G6]|

## 细化 SOP 与异常路径

需求阶段定义消息字段、引用字段、确认点与失败语义；架构阶段划分服务端密钥调用和浏览器职责；基础层封装流式客户端、错误边界、会话持久化和引用卡；业务层开发对话、Agent、RAG 或多模态页面；质量阶段覆盖断网、超时、越权、恶意 Markdown、键盘操作和长会话；上线后以灰度和监控修正状态及降级路径。[S1][S2][S4][S5][G5][G6]  
模型超时应提供重试/取消；流中断保存已完成片段；工具参数不符合 schema 时阻止执行；检索无证据时显示无法确认；WebGPU 不可用时切换服务端方案或提示能力要求。[S1][S2][S4][G3]
