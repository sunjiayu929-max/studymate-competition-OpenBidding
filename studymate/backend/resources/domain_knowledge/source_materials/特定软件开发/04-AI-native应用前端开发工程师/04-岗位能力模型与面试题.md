# AI-native 应用前端开发工程师 - 04 岗位能力模型与面试题

以下能力模型是比赛培训量表，不是招聘网站或某一仓库发布的统一行业标准。 [S1][S2]

**能力 1：流式状态。**能够解释事件顺序、消息 ID、取消、失败、完成、重复事件和恢复策略。 [S1][S2]

**能力 2：Agent 交互。**能够用状态图定义 Agent 阶段、人工确认和失败重试，并用可视化展示流程。 [G1][G2]

**能力 3：来源与安全。**能够实现引用展示、无证据提示、密钥保护和生成内容安全渲染。 [S3][S4]

**能力 4：质量与无障碍。**能够为动态 AI 页面编写异常 E2E 测试，并检查键盘、焦点和状态通告。 [S5][G3]

**能力 5：性能与端侧取舍。**能够分析长会话、Worker、缓存和 WebGPU 的收益及资源风险。 [G4][G5]

**面试题：流式内容为什么不能直接拼接到一个全局字符串？**参考回答应讨论消息边界、渲染频率、取消、重试、错误标识和会话持久化。 [S1][S2]

**面试题：怎样让多 Agent 调度过程可解释？**参考回答应包括阶段、事件、输入/输出摘要、耗时、失败原因、来源和人工重试，而不是只有动画。 [G1][G2]

**面试题：何时使用 WebLLM？**参考回答应平衡隐私/离线收益与 WebGPU 支持、模型下载、内存、耗电和降级方案。 [G4]

## 补充面试题

SSE 与 WebSocket 如何取舍？答案应说明 SSE 适合服务端向浏览器的文本推送，WebSocket 更适用于双向低延迟，需结合鉴权、代理和失败恢复选择。[S2]  
如何避免半截 Markdown 危险渲染？答案应包含缓存未闭合块、最终化渲染、清洗不可信 HTML 和错误提示。[S2][S4]  
为什么 Agent 画布需要状态机？答案应包含显式状态、事件、超时、重试和并发隔离，不能只靠局部布尔变量。[G1]
