# 企业 RAG 应用实施工程师 - 03 技术栈与实践案例

**知识接入与索引：**LlamaIndex 提供文档和节点抽象，适合作为解析、切分和元数据设计的开源参考。 [G1]

**检索：**Elasticsearch 文档说明语义检索能力；混合检索和重排是否启用，应由数据集评测决定。 [S1]

**评测：**Ragas 提供 RAG 评测指标的文档与实现参考，适用于把“回答好不好”拆解为可复验指标。 [G2]

## 开源实战案例

**案例：Haystack。**Haystack 是 Apache-2.0 许可的开源 LLM/RAG 框架，可参考其组件化管道与文档检索能力。 [G3]

**案例：LangChain。**LangChain 是 MIT 许可的开源框架，可作为检索、工具调用和应用编排的参考；实际项目需评估版本、依赖和安全边界。 [G4]

**案例：FastGPT。**FastGPT 是 Apache-2.0 许可的开源 AI 应用平台，可作为知识库应用和工作流产品形态的研究材料。 [G5]

## 技术栈分层

解析层使用 LlamaIndex Documents/Nodes 或 Haystack 文档管道；检索层可组合 BM25、向量检索、元数据过滤和重排；Elasticsearch 官方文档说明了 semantic search 的向量字段和查询方式。[S1][S2][S3]  
应用编排可选 LlamaIndex、Haystack 或 LangChain；生产选型必须固定版本、检查许可证、限制工具权限并记录依赖。[G1][G3][G4]  
评测使用 Ragas 指标结合人工标注，分别报告 context precision/recall、faithfulness、answer relevancy 和失败样本。[S4][G2]

## 复现案例卡

**案例 1：LlamaIndex 文档问答。**加载带页码元数据的文档，切成 Nodes，建立向量索引，查询时返回节点来源；验收是答案可回链到原文页码。[S2][G1]  
**案例 2：Elasticsearch 混合检索。**同时执行关键词和向量查询，按权限字段过滤，再比较 top-k 召回与延迟；验收是无权文档不会进入上下文。[S3]  
**案例 3：Ragas 回归评测。**固定黄金问题、参考答案和证据，运行指标并保存版本；任何改动必须对比旧版并分析下降样本。[S4][G2]  
**案例 4：FastGPT 工作流。**使用公开仓库研究知识库导入、工作流节点和问答调试，不能把演示配置直接视为企业安全方案。[G5]
