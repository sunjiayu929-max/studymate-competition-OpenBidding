# 企业 RAG 应用实施工程师 - 05 行业案例与官方技术文档

**实操案例：企业制度问答。**训练中可将一组已授权制度文档按部门过滤、切分并索引，要求学习者返回带版本/页面引用的答案；无命中或权限不足时必须给出明确状态。该案例是由公开 RAG 设计与安全原则组合出的训练任务，不宣称为特定企业生产系统。 [S1][S2][S3]

**训练任务 1：**比较不同切分规则对标题、表格和引用定位的影响。 [S2]

**训练任务 2：**针对同一问题比较关键词、向量和混合检索的命中文档，并依据评测样本说明选择。 [S1][S4]

**训练任务 3：**构造无权限和无证据问题，检查系统是否在生成前过滤并保留审计证据。 [S3]

## 多 Agent 训练闭环

**分析 Agent**识别问题意图、用户角色、所需资料和证据门槛；**生成 Agent**根据检索片段生成带引用答案、实操步骤或学习路径；**校验 Agent**检查引用覆盖、权限、提示注入和事实冲突；**决策 Agent**决定回答、降级解释、拒答或转人工。[S2][S5][S6]  
真实案例与模拟训练必须分开：公开仓库只能证明其实现方式，不能证明某企业的内部效果；训练任务应使用脱敏资料和可审计黄金集。[G1][G3][G5]  
三类资源映射为：定制讲义（RAG 原理/权限/评测）、实操指南（切分索引/混合检索/评测脚本）、分阶题（召回诊断/越权拦截/成本权衡）。[S1][S2][S5]

**中文补充阅读：**CSDN 文章用中文解释 RAG 的检索、增强和生成基本流程，可用于术语预习；文章不能替代官方评测、安全和权限文档。 [CSDN1]
