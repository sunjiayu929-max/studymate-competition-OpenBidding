# Docker 演示种子库

本目录保存可提交到 Git、可随后端镜像分发的脱敏 SQLite 压缩种子：

```text
studymate.db.gz
```

它与本地运行数据库 `backend/studymate.db` 完全分离。不要手工把本地数据库复制到这里。

## 当前基线内容

- 63 个获准的演示账号，包括管理员、评委、原有学习账号，以及本次新增的 20 个 YCZX 演示账号。
- 20 个 YCZX 账号全部默认绑定“前线部署工程师（FDE）”。其中 18 个账号分别包含 24 篇笔记、12 次测验、5 次面试、5 个个人知识库、12 轮岗位训练、6 次阶段评估、18 份学习资源、8 组助教对话、6 张证书和 240 条学习行为；`test1/test2` 只保留账号与默认岗位，不含使用痕迹。
- FDE 公共岗位知识库随种子库永久化，当前包含 51 条可检索片段；新浏览器登录后会从数据库默认岗位自动恢复对应课程，不再显示“岗位知识库正在建设”。
- 所有账号保留原有 Argon2 密码哈希，不保存明文密码。
- 25 门基础与岗位课程，合计 2189 个知识块。
- 1709 个基础知识块包含检索向量；480 个岗位知识块保留可追溯正文并支持关键词检索。
- 认证会话和邮箱验证码均为 0；助教会话、画像与学习事件属于保留的演示数据。

此外保留演示账号已有的画像、评估、笔记、资源和测验等演示数据。生成脚本不会修改获准账号的密码哈希。

## 重新生成

账号清单或展示内容变化后，在应用根目录依次执行：

```bash
python backend/scripts/generate_yczx_demo_assets.py
python backend/scripts/seed_yczx_demo_accounts.py --apply
python scripts/build_seed_db.py
```

第二条命令会先备份本地运行库，只重建清单内的 20 个 YCZX 账号；第三条命令再生成用于 Docker 首次启动的脱敏快照。普通后端启动不会运行这些维护脚本。

生成过程会：

1. 使用 SQLite 在线备份 API 从本地运行库创建一致快照。
2. 只保留获准的固定演示账号。
3. 清理验证码、登录会话和不应进入交付物的用户数据。
4. 修复已退役课程编号的关联记录。
5. 执行 `PRAGMA foreign_key_check` 和 `PRAGMA integrity_check`。
6. 强制核对 63 个账号、25 门课程、2189 个知识块，以及正文、基础向量和密码哈希完整性。
7. 以固定时间戳压缩为可复现的 `studymate.db.gz`。

## Docker 行为

后端镜像只复制压缩种子库。容器入口在 `/app/data/studymate.db` 不存在时解压种子；如果持久化卷中已经有数据库，重新构建或重启镜像不会覆盖线上数据。

删除 Docker 数据卷会永久清除运行数据，必须作为明确的重置操作执行，不能纳入普通升级命令。

## 核查

```bash
gzip -t backend/resources/seed/studymate.db.gz
python scripts/build_seed_db.py
```

还应把压缩文件解到临时目录，核对账号数量、课程数量、知识块数量、外键和完整性结果。完整流程见 [`../../../docs/开发与验收指南.md`](../../../docs/开发与验收指南.md)。
