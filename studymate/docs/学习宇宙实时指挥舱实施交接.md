# 学习宇宙实时指挥舱实施交接

日期：2026-07-30
范围：登录首页首屏、真实数据聚合、workspace 实时状态、三视口回归与视觉基线

## 1. 实施结果

登录后的旧“星空背景 + 六个小导航卡”已重构为单屏“学习宇宙 · 实时指挥舱”。暖白今日学习桌面及其后续功能没有重写，用户点击主 CTA 或向下滚动后继续进入原工作台。

首屏采用固定信息层级：

1. 顶部状态栏：StudyMate Learning Universe、Asia/Shanghai 秒级时间、当前课程、实时同步/部分降级/待连接。
2. 左侧：个人今日数据与平台基础能力明确分区。
3. 中央：放大的学习者核心、当前课程、今日闭环进度、七颗分级能力星球和主 CTA。
4. 右侧：Retriever、Doc、MindMap、Quiz、Reading、Code、Path 七个 Agent 的真实 workspace store 状态。
5. 底部：真实学习脉冲、最近事件和近 7 日真实事件构成。

宇宙可见期间，`AppShell` 左侧栏和全局悬浮数字人均隐藏；进入暖白工作台后恢复原行为。没有新增或替换数字人素材，也没有实现连续视频数字人。

## 2. 数据来源与口径

### 2.1 个人实时数据

个人数据只来自当前登录用户的既有接口和当前浏览器 workspace store：

- 画像完整度：`GET /api/profile/{user_id}`，按知识基础、认知风格、学习目标、薄弱点、学习节奏、内容偏好、就业技能七组是否有有效值计算。
- 笔记与最近动态：`GET /api/notes` 的 `created_at / updated_at`。
- 测验、完成任务和已记录时长：`GET /api/quiz-sessions` 的 `status / submitted_at / duration_ms`。
- 画像评估与事件：`GET /api/eval/history/{user_id}` 的 `created_at / suggestions`。
- Agent 状态、资源、学习时长和工作台事件：workspace store 的 `status / agents / agentStatus / outputs / resourcesConsumed / learningDurationMs / startedAt / finishedAt / updatedAt / logs`。

“今日”按 Asia/Shanghai 日期边界计算。今日学习时长使用 workspace 已记录时长与今日已提交测验时长中的较大值，避免同一次测验被重复累计；完成任务只计今日已提交测验和今日完整结束的 Agent 任务；接触知识点只来自今日测验主题与今日 workspace 主题，不把课程知识块数量描述为个人掌握。

今日闭环进度按四类真实证据计算：今日笔记、今日测验、今日完整 Agent 任务、今日画像评估，每类 25%。该进度不是成绩或掌握率。

### 2.2 平台基础能力

平台区明确标注“平台基础能力”，与个人指标分开。默认产品基线为 5 门课程、1709 个知识片段、300 个可视讲解主题和 7 个协作 Agent；页面同时请求：

- `GET /api/courses` 获取当前课程数与课程知识块汇总；
- `GET /api/rag/stats` 获取当前运行库知识片段数。

两项都成功时显示“实时汇总”，否则保留明确的“产品基线”口径。运行库实时知识片段数可能高于文档基线，不会冒充个人学习成果。

### 2.3 Agent 状态

右栏优先读取 workspace `agents` 和 `agentStatus`：

- `pending`：待命；
- `running`：执行中；
- `streaming`：生成中；
- `done`：已完成；
- `error`：异常；
- 整轮 `interrupted` 对应的节点显示“已降级”。

没有运行任务时七项统一显示真实待命。只有 workspace 正在运行时飞船才强化为任务语义；空闲时只是低透明度装饰巡航，不附带检索或生成文案。

## 3. 空态与单卡降级

- 没有个人学习时间时显示真实 `0 分钟`，其他零指标使用“尚未开始”“等待学习”等状态词，避免四处重复 0。
- 没有事件时显示“尚无个人学习事件”及“选择课程/生成第一次学习任务”入口。
- 没有近 7 日记录时只画零基线并显示“暂无历史，不绘制虚假曲线”。
- 画像、笔记、测验、评估、课程或 RAG 任一请求失败时，只把对应卡标为数据源不可用；顶部同步状态改为“部分降级”，其他数据和入口继续可用。
- 正式页面没有模拟个人时长、模拟成绩、虚构 Agent 业务状态、虚构事件、演示数据徽标或 fixture。测试 fixture 只存在于浏览器路由拦截的自动布局回归中，不进入运行代码。

## 4. 动画与可访问性边界

- 动画包括一次性进场、低频星层漂移、轨道流光、核心受光/自转感、七星球微动、节点信号、远景彗尾、轻微鼠标视差和飞船巡航。
- `IntersectionObserver` 在首屏可见比例降到阈值后把宇宙标记为 inactive，CSS 暂停星层、轨道、核心、星球、信号、飞船和 Agent 状态动画。
- `prefers-reduced-motion: reduce` 下关闭进场、视差相关动态、彗尾、飞船、轨道/星球/信号动画；所有数据、星球链接和 CTA 仍可用。
- 彗尾位于顶层卡片外的远景区域；飞船只在中央轨道内运行；二者不覆盖顶部时钟、左右数据卡和 CTA。
