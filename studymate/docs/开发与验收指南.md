# StudyMate 开发与验收指南

> 最后核对：2026-07-21。以下命令从 `studymate/` 应用根目录执行，除非小节另有说明。

## 1. 开发前检查

```bash
git status --short
cp -n .env.example backend/.env
docker compose config --quiet
```

- 不覆盖已有 `.env`，不在终端输出真实密钥。
- 脏工作树中的既有改动属于当前开发者，修改前先确认范围。
- 本地库、日志、备份、`node_modules`、`.venv` 和 `dist` 必须处于忽略状态。

## 2. 后端检查

```bash
cd backend
PYTHONPYCACHEPREFIX=/tmp/studymate-pycache python -m compileall -q app scripts
python -m unittest discover -s tests -v
```

启动后至少验证：

```bash
curl -fsS http://127.0.0.1:8000/api/ping
```

涉及认证或业务接口时，应使用 Cookie 文件完成登录、`/api/auth/me`、目标接口和退出登录的连续检查。不要把 Cookie 文件或响应中的凭据提交到仓库。

## 3. 前端检查

```bash
cd frontend
npm run lint
npm run build
node --check scripts/capture-page.mjs
```

本地前端服务启动后，可运行建议项核心回归（接口由脚本隔离模拟，不写数据库）：

```bash
STUDYMATE_BASE_URL=http://127.0.0.1:5173 node scripts/check-suggestion2.mjs
STUDYMATE_BASE_URL=http://127.0.0.1:5173 node scripts/check-suggestion3.mjs
STUDYMATE_BASE_URL=http://127.0.0.1:5173 node scripts/check-suggestion4.mjs
STUDYMATE_BASE_URL=http://127.0.0.1:5173 node scripts/check-suggestion5.mjs
STUDYMATE_BASE_URL=http://127.0.0.1:5173 node scripts/check-suggestion6.mjs
```

当前未启用 React Compiler。ESLint 只启用 `react-hooks/rules-of-hooks` 与 `react-hooks/exhaustive-deps`，不启用 compiler 专用规则；如需启用编译器，应作为独立迁移重新评估动画 Canvas 的 ref 读取与状态更新方式。

手工走查至少覆盖桌面与窄屏：登录、课程切换、画像、工作台、助教、笔记、测验、报告、可视讲解、反馈。`judge` 或 `admin` 还需检查 `/tests`。

## 4. 种子库检查


临时解压后确认：

- 演示账号为批准清单，当前应为 34 个。
- 课程数为 5，知识块数为 938。
- 用户会话和邮箱验证码为 0。
- 本地运行库 `backend/studymate.db` 未被加入 Git。

## 5. Docker 检查

```bash
docker compose config --quiet
docker compose build backend frontend
docker compose up -d
docker compose ps
curl -fsS http://127.0.0.1:8000/api/ping
```

涉及种子或容器入口时，必须额外用全新的临时数据卷启动，确认日志显示“解压种子库”，并核对数据库数量。不要删除开发者正在使用的正式数据卷。

可选服务按改动范围验证：

```bash
docker compose --profile code-runner up -d piston-api
bash scripts/init-piston.sh
docker compose --profile public config --quiet
docker compose --profile extras config --quiet
```

Piston 验收除 Python/C/C++ 基础运行外，还应实际执行：`import numpy, scipy, sklearn, matplotlib, seaborn, PIL, pandas, networkx`，并调用 `GET /api/run/capabilities` 核对白名单。避免代码案例只在页面显示、进入沙箱后才发现依赖缺失。

## 6. 接口冒烟建议

登录后至少检查：

1. `GET /api/auth/me`：Cookie 会话有效。
2. `GET /api/courses`：返回 5 门课程。
3. `GET /api/rag/stats`：知识块统计正确。
4. `GET /api/tutor/conversations`：按当前用户返回会话。
5. `GET /api/rencaiya/courses?course_id=1&keyword=梯度下降&limit=2`：返回合法来源状态和匹配级别；只有 `exact`/`related` 才带课程卡片。
6. `POST /api/reading/resolve`：用论文、图书和博客样例确认只返回白名单详情页；无可靠匹配时返回空解析结果，由前端继续使用搜索入口。
7. `GET /api/careers/recommendations?course_id=1&limit=2`：返回匹配分数、优势与差距，不泄露其他用户数据。
8. `POST /api/auth/logout`：旧会话随后失效。

真实 LLM、语音与 Piston 会产生费用或依赖外部服务，应在明确配置和预算后单独验收，不能用“接口能启动”替代真实能力验证。

## 7. 文档检查

先运行工作区结构检查：

```bash
PYTHONDONTWRITEBYTECODE=1 python scripts/check_workspace_structure.py
```

- Markdown 本地链接全部可达。
- 不再引用旧文件名 `DEPLOY_UBUNTU.md`、`SECRETS.md` 或已拆分的累计日志。
- `.env.example` 中的变量与 `backend/app/core/config.py` 一致。
- README、架构、接口和部署文档中的课程数、知识块数、画像维度与动画数量一致。
- 交付 DOCX/PDF 由 `docs/交付文档/生成脚本/generate_docs.py` 生成到 `docs/交付文档/交付文件/`，并抽取文本检查关键术语。
- 文档与代码中不出现真实 Key、密码清单、Cookie 或本地临时文件路径。

## 8. 交付验收矩阵

| 项目 | 通过标准 |
| --- | --- |
| 登录与权限 | 学生、评委、管理员边界符合接口说明；生产 Cookie 启用 Secure/HttpOnly |
| 课程与 RAG | 5 门课程可切换，938 个知识块可检索和追溯；原始 RRF 排序不变，相对匹配度可解释且默认展示 8 条 |
| 工作台 | 7 个协作者能展示进度并生成对应资源；资源详情顶部和底部都能按同一顺序翻页 |
| 助教 | 课程会话、SSE、附件和页面上下文正常；长内容不撑宽消息区，`/tutor?capture=1` 可展开完整对话截图；图片请求使用视觉模型 |
| 学习路径 | 阶段按深度连续编号，每行最多 4 个并蛇形回折；历史直线布局也由前端兼容重排 |
| 测验与报告 | 未作答只显示单一标签；报告展示主题×难度热力图、完成率、资源覆盖和参与度分项，并按来源版本安全写回 |
| 可视讲解 | 注册表总计 300 个主题，五门课各 60 个；工作台显式生成后预取并复用结果 |
| 外部资源 | 只展示知识点级高相关卡片；论文、图书和博客直链必须经过白名单与标题校验，解析失败保留稳定搜索入口，知网只搜索用户选定主题 |
| 岗位推荐 | 推荐理由可解释，个人画像不发送给第三方 |
| Docker | 空卷能解压种子，有数据卷升级不覆盖，健康检查通过 |
| 安全 | Git 中无真实密钥、运行库、日志和备份；生产密钥已轮换 |
| 文档 | 当前文档与代码一致，已失效材料已删除，生成版已更新 |

## 9. 已知上线前风险

- `courses` 的新增/删除和 RAG 导入/清空当前只要求登录，生产上线前应限制为系统管理员。
- 带 `user_id` 的画像与评估接口应继续审计资源所有权，避免普通用户访问或修改他人数据。
- 数据库迁移仍由启动期轻量逻辑承担，长期维护应改为 Alembic。
- 外部平台接口可能改变，必须保留超时、缓存、数据清洗和兜底，并监控失败率。
