# 因材智训接口说明

> 最后核对：2026-08-01。当前代码注册 92 个方法-路径操作，折叠不同 HTTP 方法后为 78 个唯一路径。实际请求模型和响应结构以运行中的 OpenAPI 文档 `/docs` 为准；本文用于维护接口分组、认证方式和功能边界。

## 1. 通用约定

- API 前缀：`/api`。
- 数据格式：除文件上传与 SSE 外均使用 JSON。
- 认证方式：登录后由浏览器自动携带 HttpOnly `sm_session` Cookie。
- 未登录：受保护接口返回 `401`；角色不足返回 `403`。
- 角色：`student`、`judge`、`admin`。
- SSE：助教和部分测试接口返回事件流，前端需要逐事件处理，不能等待完整 JSON。
- 交互式文档：后端启动后访问 `/docs` 或 `/redoc`。

## 3. 画像与评估

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/profile/{user_id}` | 读取学习画像 |
| `POST` | `/api/profile/{user_id}/reset` | 重置画像 |
| `POST` | `/api/profile/chat` | 通过对话更新画像 |
| `POST` | `/api/eval/run` | 运行学习效果评估 |
| `POST` | `/api/profile/apply-delta` | 将评估增量写回画像 |
| `GET` | `/api/profile/snapshots/{user_id}` | 查询画像快照 |
| `GET` | `/api/eval/history/{user_id}` | 查询评估历史 |

画像包含知识基础、认知风格、目标、薄弱点、节奏、偏好和就业技能 7 组数据。

- `/api/profile/chat` 的最终 SSE `patch` 事件包含 `changed`、`changed_fields` 和可选 `warning`。只有画像实际变化时才新增快照和版本。
- `/api/eval/run` 同时返回 `current_dims` 与 `projected_dims`，供前端在确认写回前预览画像变化。
- `/api/eval/run` 的 `engagement` 可带 `resources_available`；`scores` 在保留原有正确率和参与度字段的同时，增加 `by_topic_difficulty`、`answer_completion`、`resource_coverage` 和 `engagement_breakdown`。旧客户端不传新字段仍可正常评估。
- `/api/profile/apply-delta` 可传 `source_version`。版本过期返回 `409`；响应中的 `changed=false` 表示没有实际字段变化，也不会生成多余快照。

## 4. 课程与 RAG

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/courses` | 获取课程列表 |
| `POST` | `/api/courses` | 新增课程；当前代码为登录可用，生产前应收紧管理权限 |
| `GET` | `/api/courses/registry` | 获取课程注册表 |
| `GET` | `/api/courses/{course_id}/config` | 获取课程配置 |
| `DELETE` | `/api/courses/{course_id}` | 删除课程；当前代码为登录可用，属于待收紧管理接口 |
| `GET` | `/api/rag/stats` | 知识库统计 |
| `POST` | `/api/rag/ingest` | 导入知识块 |
| `GET` | `/api/rag/search` | 混合检索 |
| `GET` | `/api/rag/chunks/{chunk_id}` | 获取知识块原文 |
| `DELETE` | `/api/rag/all` | 清空知识库；当前仅要求登录，正式环境应限制管理员 |

`/api/rag/search` 保留原始 RRF `score` 和排序，并为每条结果增加 `rank`、`relevance_percent`、`retrieval_mode`。响应中的 `score_meta` 解释相对匹配度口径；该百分比只比较本次结果，不代表答案正确概率。

用户私有知识库接口全部要求登录，并以 Cookie 对应的用户为所有权依据，不接受请求体伪造 `user_id`：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET`、`POST` | `/api/knowledge-bases` | 列出或创建当前用户私有库 |
| `PATCH`、`DELETE` | `/api/knowledge-bases/{library_id}` | 更新绑定/元数据或删除私有库 |
| `POST` | `/api/knowledge-bases/{library_id}/documents` | 上传 PDF、PPTX、DOCX、Markdown、TXT，返回 `202 queued` 后由后台任务解析 |
| `POST` | `/api/knowledge-bases/documents/{document_id}/retry` | 对当前用户失败任务做安全重试，最多 3 次 |
| `DELETE` | `/api/knowledge-bases/documents/{document_id}` | 删除当前用户资料及分片 |
| `GET` | `/api/knowledge-bases/{library_id}/search` | 库内检索，返回来源文件与页码 |

未配置向量 Key 时，资料状态为 `ready_keyword`、`vector_progress=0`，关键词检索仍可用；不会把未执行的向量化显示为完成。

资料状态包括 `queued`、`parsing`、`vectorizing`、`ready`、`ready_keyword`、`error`。响应还包含 `retry_count`、`retry_available`、`ocr_status` 和开始/完成时间。扫描 PDF 未配置 OCR 时为 `error + required_unconfigured`，原文件仍保留；原文件路径与校验和不返回浏览器。删除资料/知识库会同步清理原文件、分片与向量。

## 5. 多智能体工作台与助教

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/workspace/role-context` | 按 `course_id` 返回领域、目标岗位与核心能力 |
| `POST` | `/api/workspace/generate` | SSE 运行诊断、三生成、三审核、裁决/返工与发布闭环 |
| `GET` | `/api/workspace/runs/{run_id}` | 读取当前用户的一次闭环审计记录 |
| `POST` | `/api/workspace/feedback` | 提交答题证据并生成下一轮画像/资源策略 |
| `POST` | `/api/workspace/append-quiz` | 向现有资源追加测验 |
| `GET` | `/api/tutor/conversations` | 获取当前用户课程会话 |
| `PUT` | `/api/tutor/conversations/active` | 设置或修复活动会话 |
| `POST` | `/api/tutor/conversations/new` | 新建会话 |
| `POST` | `/api/tutor/conversations/{conversation_id}/activate` | 切换活动会话 |
| `PUT` | `/api/tutor/conversations/{conversation_id}` | 重命名会话 |
| `DELETE` | `/api/tutor/conversations/{conversation_id}` | 删除会话 |
| `POST` | `/api/tutor/extract-file` | 提取 PDF、Markdown、文本或代码附件 |
| `GET` | `/api/tutor/models` | 返回 Qwen、DeepSeek、讯飞星火、MiMo 的可用状态与服务端默认项，不返回 Key 或 Base URL |
| `POST` | `/api/tutor/chat` | 岗位助教 SSE 对话 |

`/api/tutor/chat` 接受显式 `provider` 和可选 `knowledge_base_id`，并注入课程、画像、页面、学习模式与当前用户私有库上下文。图片问答只接受用户显式选择 Qwen；其他模型不会被服务端静默替换。模型凭据始终只存在服务端。

PPT 接口同样要求登录，并复用助教模型白名单：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/ppt/outline` | 结合课程 RAG/当前用户私有库生成结构化大纲、引用与图表页 |
| `POST` | `/api/ppt/rewrite` | 使用所选模型和同一知识上下文重写单页 |

两个接口都要求显式 `provider=qwen|deepseek|spark|mimo`。所选模型未配置或调用失败时返回明确错误，不会静默切换；只有请求明确传 `allow_local_fallback=true` 才返回 `mode=local_fallback`。引用只能来自本轮检索上下文，模型输出还会经过页数、版式、要点数和字段校验。

## 7. 可视讲解、语音、OCR 与代码运行

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/concept/explain` | 解析概念并返回讲解脚本或动画匹配结果 |
| `GET` | `/api/voice/status` | 只读返回 ASR/TTS 是否已配置、TTS 引擎及 `user_gesture_only` 权限策略；不调用外部语音服务 |
| `GET` | `/api/voice/voices` | 查询可用音色 |
| `POST` | `/api/voice/asr-url` | 生成讯飞 ASR 鉴权地址 |
| `POST` | `/api/voice/tts` | 文本转语音 |
| `POST` | `/api/ocr/topic` | 从图像识别知识主题 |
| `POST` | `/api/ocr/text` | 从图像识别文本 |
| `GET` | `/api/run/languages` | 查询代码运行语言 |
| `GET` | `/api/run/capabilities` | 查询沙箱支持的语言与第三方库白名单 |
| `POST` | `/api/run` | 通过 Piston 运行代码；Python 源码会先做 import 白名单校验 |

语音页先读取 `/api/voice/status`。ASR 未配置时必须展示演示降级并保留文字对话，不申请麦克风；即使服务已配置，浏览器也只允许在用户明确点击后申请权限。该状态接口不代表一次真实 ASR/TTS 调用成功。

`/api/run/capabilities` 返回当前固定支持的语言，以及 Python 第三方库白名单（`numpy` / `scipy` / `sklearn` / `matplotlib` / `seaborn` / `PIL` / `pandas` / `networkx`）。`/api/run` 在转发到 Piston 前会静态检查 Python import；不在白名单的第三方库会直接返回友好错误，而不是沙箱 `ModuleNotFoundError`。标准库始终允许。matplotlib 使用 `Agg` 后端，当前接口不返回图片字节。

## 8. 外部学习资源与岗位推荐

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/bili/videos` | 按岗位任务、规范能力点和岗位上下文搜索并过滤哔哩哔哩公开视频 |
| `GET` | `/api/rencaiya/courses` | 按可选 `keyword` 获取人才呀岗位能力点相关课程及匹配级别 |
| `POST` | `/api/reading/resolve` | 批量将生成的论文、书籍和博客标题解析为经过白名单校验的真实详情页 |
| `GET` | `/api/careers/recommendations` | 返回本地可解释岗位推荐 |

`/api/bili/videos` 可选传入 `concept_title` 和 `course_name`；`/api/rencaiya/courses` 返回 `match_level` 与 `resolved_query`。前端只展示 `exact` 或 `related` 课程，课程级泛化结果改为平台入口。

`/api/reading/resolve` 每次最多接收 12 项，只处理 `paper`、`book` 和 `blog`。服务会查询 arXiv/Crossref、豆瓣图书以及指定来源的 CSDN 或掘金，并只返回经过标题相似度、HTTPS、主机和路径格式校验的 arXiv 摘要页、DOI、豆瓣图书详情页、CSDN 文章页或掘金文章页；没有可靠匹配时不返回伪造直链，由前端继续展示搜索入口。外部请求并发上限为 4、单次超时 6.5 秒，成功和未命中结果均缓存 6 小时，进程内最多 512 项。

外部课程和阅读解析只发送清洗后的技术主题、公开资源标题及来源名称，不发送用户标识、画像、对话历史或认证信息。岗位推荐只在本地读取用户画像和测验课程历史。

## 11. 维护提醒

- 新增、删除或改名接口时，同时更新本文、前端 API 客户端和用户指引。
- `workspace/generate`、运行记录和反馈接口已从当前会话识别用户并验证运行所有权；`profile`、`eval`、`notes` 等其他历史接口仍需继续统一多租户所有权审计。
- 课程写操作、RAG 导入和清空当前只受登录保护，是上线前应优先收紧的权限边界。
