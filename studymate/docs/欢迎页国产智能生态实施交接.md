# 欢迎页国产智能生态实施交接

> 实施日期：2026-07-30
> 页面范围：`frontend/public/landing/index.html`
> 目标路径：`/landing/index.html`

## 1. 实施范围

本轮只在登录前欢迎页增加“国产智能生态与成长路径”章节，并按视觉反馈压缩紧随其后的学习宇宙 `#solar`。生态章节位于真人助教 `human-section` 与学习宇宙之间。

本轮没有修改：

- `frontend/src/pages/Home.tsx`
- `frontend/src/index.css`
- 其他 React 源码
- `package.json` 或任何 lock 文件
- 公共 README、架构文档
- `frontend/dist/`

运行页面没有加载远程 Logo、字体、脚本或图片，也没有调用模型、语音、人才呀、Bilibili 或其他外部资源 API。页面使用用户提供的真实界面截图，并压缩为 `talent-catalog-real.webp`、`talent-course-grid-real.webp`、`studymate-career-recommendations-real.webp` 与 `spark-official-home-real.webp`；运行时只读取本地文件。此前视觉过于模板化的三张人才呀课程封面已移除。`frontend/preview/` 下的 PNG 仅用于本地视觉验收，不被页面加载。

## 3. 真实能力边界

### 3.1 星火 × DeepSeek

- 统一主流程适配层已支持 `spark` 与 `deepseek`。
- `SPARK_MODEL` 当前配置为 `x1`。
- `LLM_PROVIDER` 当前默认值是 `deepseek`。
- 欢迎页使用“星火 × DeepSeek 核心生成链路双驱动”“服务端可配置选用”。
- 欢迎页没有宣称运行时自动调度、同时推理或全站一键切换。
- 双引擎节点使用简短状态签：
  - 星火：`已接入 · 可配置`
  - DeepSeek：`当前默认`
- 节点下固定说明：“服务端配置选用；助教 / PPT 采用专项模型白名单。”

### 3.2 专项引擎

- 助教与 PPT 当前显式模型白名单为 Qwen、DeepSeek、MiMo，不包含 Spark。
- 图片问答当前只允许显式选择 Qwen。
- 语义检索使用 Qwen `text-embedding-v3`。
- 讯飞语音是独立的 ASR/TTS 服务能力，不跟随主流程 LLM 配置切换。

### 3.3 讯飞语音

- ASR 使用浏览器直连讯飞流式 IAT WebSocket。
- 浏览器只在用户明确操作后申请麦克风权限。
- TTS 由后端代理讯飞 WebSocket 合成。
- 欢迎页仅展示能力关系，不申请权限、不读取语音状态、不调用语音接口。

### 3.4 人才呀与职业建议

- 只表达“连接讯飞人才呀公开课程与岗位目录”。
- 不表达官方合作、联合开发、官方指定或企业精准匹配。
- 课程检索只发送清洗后的技术主题或课程名称。
- 职业方向综合就业技能、当前课程、已提交测验课程和学习目标在 StudyMate 后端本地计算。
- 用户标识、画像、对话历史和认证信息不发送给人才呀。

### 3.5 外部学习资源

- Bilibili 节点表达“按知识点筛选公开学习视频”，没有高相关结果时保留精确搜索入口。
- 论文、图书、博客只有通过标题、HTTPS、主机和路径校验后才提供详情直达。
- 未可靠匹配的内容明确保留搜索入口，不伪造原文链接。

## 4. 滚动与交互

### 4.1 两幕静态展开

章节仍保留七个阶段的语义和 SVG 路径，但每一幕进入视口后立即展示该幕完整链路：

- 第一幕直接显示语音、双引擎、Qwen/MiMo 与 7 Agents；
- 第二幕直接显示资源、画像、人才呀与职业方向。

每幕由独立的 `IntersectionObserver` 选择当前活动画面并一次性点亮到本幕最大步骤。已移除往返计时器、滚动接管和节点暂停倒计时，因此不会再出现等待点亮、长时间变暗或让用户误以为滚动失效的状态。状态签固定显示“完整链路已展开 / 节点可探索”。

### 4.2 能量与语音状态

- SVG 主路径在当前幕进入视口时直接点亮。
- 低频能量流使用同一路径上的短线段动画，周期为 4.8 秒。
- 语音节点使用八条低频波形，周期为 2.8 秒。
- 两幕均离屏或浏览器标签隐藏后，循环动画进入暂停状态。

### 4.3 节点交互

- 所有可交互节点使用原生 `<button type="button">`。
- hover、键盘 focus 或点击节点时，固定信息栏显示一条真实能力说明。
- `Escape` 可退出节点焦点并恢复默认说明。
- 交互不打开外部页面，也不发起 API 请求。

## 5. Reduced motion 与移动端

### Reduced motion

当 `prefers-reduced-motion: reduce` 生效时：

- 所有节点和路径直接显示最终状态；
- 两幕保持普通文档流；
- 能量流和循环波形停止；
- CTA、信息层级与键盘交互保留。

### 移动端

`820px` 以下取消绝对坐标网络与 SVG 路径，改为原生 DOM 单列时间线。节点顺序仍为语音、双引擎、Agents、资源、画像、人才呀、职业方向。

`520px` 以下：

- 星火与 DeepSeek 从双列改为上下排列；
- 人才呀课程和岗位改为单列；
- CTA 使用全宽布局；
- 页面最小宽度继续遵循现有 `320px` 基线。

## 6. 性能策略

- 不使用 Canvas、WebGL、视频背景或粒子系统。
- 运行页面新增四张由用户真实截图压缩得到的 WebP，并复用三张已有 StudyMate 系统截图；四张新增 WebP 合计约 304KB，不新增运行时网络请求。
- 动画只改变 `opacity`、`transform` 与 SVG stroke。
- 只有循环声纹和 SVG 能量线在当前海报进入视口时运行；没有生态演示 interval。
- 没有定时轮询、接口预取或权限请求。
- 所有装饰内容都在局部 `overflow: clip` 容器中，避免制造横向滚动。

## 8. 当前限制

- “双驱动”表示统一主流程适配层同时支持星火与 DeepSeek，并由服务端配置选择，不表示用户级全站即时切换。
- 欢迎页是静态能力说明，不读取运行中的模型或语音配置状态。
- 外部公开视频、课程、岗位和阅读详情受第三方平台可用性影响；欢迎页不会提前访问这些服务。
- 欢迎页中的人才呀目录、岗位推荐与星火官网画面都是本地静态快照，不表示课程内容、目录状态、模型状态或合作关系实时有效；真实目录和运行配置仍以应用接口结果为准。
- 常规移动端 `390px` 无横向溢出；在 `320px` 极限宽度下，现有整页的全局 `body { min-width: 320px }` 会与桌面浏览器的 15px 滚动条槽共同形成既有横向边界。新章节内部所有内容仍收在 16px 边距内，未新增越界元素。
- `frontend/preview/landing-concept.html` 是历史预览副本，与运行时页面内容和哈希不同，本轮没有把它当作第二套源文件同步。
- `frontend/dist/` 需要在并行任务结束后由主任务统一构建。
