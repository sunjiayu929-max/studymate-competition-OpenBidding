# 2026-07-29 第二阶段实施交接

本文记录第二阶段增量实现与验证边界。全部工作保留第一阶段现有设计，不包含账号、Key、Cookie 或部署信息，也没有启动或测试 Piston。

## 已完成闭环

### AI 视频讲解真实时间轴

- 每个动画通过现有讲解节拍注册可计算时长；未取得音频时使用明确的文本估算，TTS 音频 metadata 就绪后以实际 `duration` 覆盖。
- 当前时间/总时长、拖动 seek、节拍内动画帧定位、逐句字幕高亮、暂停/继续、重播和 0.75/1/1.25/1.5 倍速共享同一内容时钟。
- seek 会中断旧音频并从目标拍内偏移继续，不复用旧播放回调；暂停时音频与动态帧同时停止推进。
- 保留第一阶段普通模式内容自适应高度和独立全屏布局，没有重新增加固定播放器高度或底部黑边。

### PPT 生成深化

- 新增 `POST /api/ppt/outline` 与 `POST /api/ppt/rewrite`，服务端只接受 Qwen、DeepSeek、MiMo 白名单标识并读取服务端配置。
- 大纲与单页重写复用当前课程 RAG、当前用户私有知识库和来源页码；私有库查询继续按登录用户隔离。
- 所选模型未配置或调用失败时明确提示，绝不静默切换其他模型。只有用户点击“明确使用本地策略”后才发送 `allow_local_fallback=true`。
- 模型输出经过 JSON、页数、字段、版式、每页要点数和引用结构校验；本地策略同样返回明确 `mode=local_fallback`。
- 前端增加引用来源查看、三种视觉模板、单页版式选择和可编辑数据图形页。图表由 PowerPoint 文本/形状元素组成，不是截图。
- 保留大纲确认、文字编辑、拖动/按钮排序和真实可编辑 `.pptx` 导出；PptxGenJS 继续按路由懒加载。

### 私有知识库后台任务

- 上传接口校验并持久化原文件、SHA-256 和 `queued` 任务后返回 `202`；解析与向量化在请求结束后的独立数据库会话中执行。
- `queued/parsing/vectorizing/ready/ready_keyword/error`、解析/向量进度、开始/完成时间、错误详情和重试次数均持久化。
- 服务重启会把上次中断任务明确改为 `error`，保留原文件并允许安全重试；重试只对所有者开放，校验受控路径与原文件，最多 3 次。
- 原文件存放于 `PRIVATE_KNOWLEDGE_DIR/{user_id}/`，路径和校验和不返回浏览器。删除资料或知识库会同步清理原文件、文本分片和向量。
- 扫描 PDF 没有文字且 OCR 未配置时标记 `required_unconfigured`；前端明确显示 OCR 可插拔但当前未配置，不伪装解析成功。
- 前端持续轮询活动任务，展示队列、解析、向量化、失败与 OCR 状态，并提供安全重试。

### 数据运维可见性

- 启动迁移和课程增量导入写入 `system_migrations`，当前记录私有知识后台任务迁移与种子课程目录导入版本。
- 管理员测试管理页增加只读数据健康卡，展示课程、课程知识块、向量、私有库/分片、任务状态、OCR 插件状态和最近迁移。
- `/api/admin/data-health` 只允许 `admin`，没有增加开放平台、API Token 或开发者调试台。

### 回归与性能预算

- 新增讲解时间估算和节拍边界 seek 状态检查。
- 新增私有知识后台处理、来源保留、所有权重试、PPT 显式降级/图表页和数据健康迁移测试。
- 新增路由块预算：ConceptPlayer、PPT、知识库与测试管理保持独立小块；PptxGenJS 保持独立懒加载。
- 当前检查记录的最大静态栅格资源约 1.64 MiB。该上限只用于防止继续变大，不代表已达到理想 LCP 目标。

## 当前属于 MVP 的部分

- 后台任务使用 FastAPI 进程内 `BackgroundTasks`，但状态、原文件和重试是持久的。单机演示与中等文件可用；多实例生产环境仍应接入 Redis/Celery/RQ 等外部队列并增加租约/幂等消费。
- OCR 仅完成可插拔状态、扫描 PDF 识别和安全重试路径，没有内置 Tesseract、云 OCR 或 PDF 页面渲染器。
- PPT 模型接口已经走真实受控客户端，但本地没有模型 Key，因此只自动验证“未配置明确失败”和“用户显式本地降级”；没有产生付费调用。
- 数据图形支持直接编辑标签和数值并导出可编辑形状，不是完整 PowerPoint 图表设计器；图片生成、自由画布和母版编辑未实现。
- 时间轴会读取真实音频时长，但本轮没有 TTS Key，未验证不同浏览器对具体编码的 metadata、倍速音质和 seek 精度。

## 本轮未完成

- 独立的“评委演示模式”尚未实现。现有 `JudgeTour` 是普通新手指引，不会写入预置演示数据，也不能冒充隔离的一键演示与复位。
- 完整关键路径 Playwright E2E（介绍页→登录→学习宇宙→课程→私库来源→画像首屏→视频 seek/倍速→数字人→语音降级）尚未形成单个全流程脚本；现有后端、状态和既有建议项脚本只覆盖其中部分。
- 固定评委设备上的真实 LCP、INP 与长任务采集未执行。最大静态图片仍明显偏大，数字人和 landing PNG 需要后续 WebP/AVIF、响应式尺寸与首屏加载优先级专项。
- 外部任务队列、生产 OCR、完整 PPT 编辑器、真实短循环数字人视频、部署和真实密钥验证均不在本轮范围。
