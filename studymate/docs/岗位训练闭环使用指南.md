# 岗位训练闭环使用指南

## 功能定位

岗位训练中心以领域与目标岗位执行可审计训练闭环。岗位知识库是检索与数据隔离边界，前端任务、诊断、资源和审核均以目标岗位能力组织。

当前已经接入完整知识库并可运行闭环的是：

- 领域：特定软件开发
- 目标岗位：前线部署工程师（FDE）
- 核心能力：需求澄清、Python 与 SQL、系统集成、客户沟通、交付验证

岗位空间同时展示工业互联网、特定软件开发、人工智能三个领域共九个岗位。除 FDE 外的岗位明确标记为“待建设”；选择会被保存并同步回岗位训练中心，但在专属知识库接入前不会开放生成按钮，也不会借用无关知识冒充岗位内容。

## 闭环流程

一次运行依次经过：

1. 学情诊断：读取知识基础、薄弱能力点和岗位目标，输出当前水平、目标难度、能力盲区及本轮训练合同。
2. 岗位检索：只在当前目标岗位知识库内检索六个证据片段，作为讲义与实操指南的引用依据；底层 `course_id` 仅承担兼容的数据隔离。
3. 三类生成：定制讲义、实操指南、分阶测试并行生成。
4. 三项审核：事实与来源、实操规范、难度与能力覆盖分别审核，输出分数、指标和纠偏意见。
5. 总裁决：依据结构化审核结果只决定“批准发布”或“定向返工”。
6. 自动返工：任何审核问题都会携带修改要求退回涉及的讲义、指南或测试，随后重新生成、交叉审核和裁决，直到全部审核通过；连续三轮问题完全没有改善时按运行异常安全终止，且仍禁止发布。
7. 发布：审核通过后只解锁岗位定制讲义、实操指南和岗位分阶测试；思维导图、拓展阅读、代码案例、学习路径和可视讲解仅保留入口，当前阶段不生成或预取内容。
8. 反馈更新：学习者完成分阶测试后提交真实答题证据，系统给出动态迭代策略、写回本轮审计记录，并同步回写画像（追加 `training_rounds` 训练轮次证据、按表现更新 `weak_points`、画像版本 +1、保存快照）。正确率达到 66.6% 时，“成果验收与下一轮”同时开放“进阶挑战任务”和“启动下一轮”两个入口；进入挑战后会自动打开智能测验新建弹窗、预填当前任务点并设为进阶难度。低于阈值时沿用现有降维解释与补强路径。

## 前端如何使用

1. 登录后进入“岗位训练中心”。
2. 点击“选择目标岗位”进入岗位空间，依次选择领域和岗位；选定后会自动返回岗位训练中心，并在顶部、侧栏与能力地图中同步显示当前岗位。
3. 完成岗位画像后点击“启动多 Agent 协同决策”，系统依据能力地图自动选择本轮岗位任务。
4. 在流程板查看当前阶段、11 个核心 Agent 分类、诊断盲区、三项审核分数、返工回路和裁决结果。
5. 若发生返工，页面会显示返工轮次、目标资源与修改要求；生成角色会重新进入运行状态，无需用户操作。
6. 只有显示“批准发布”后，资源卡片才可打开。优先阅读岗位定制讲义和实操指南，再完成岗位分阶测试。
7. 返回岗位训练中心，在“成果验收与下一轮”区域提交答题证据，查看下一轮难度与训练策略。

系统不存在人工复核分支。裁决不通过时会直接定向返工；任何未通过审核或运行异常的资源都不会被伪装成正式成果。

## 可审计数据

每次运行写入 `training_runs`，保存运行编号、用户、兼容知识库 ID、领域、目标岗位、任务、阶段、生成轮次、诊断、最终资源、三项审核、裁决和反馈。正式资源只在裁决为 `publish` 时写入 `resources` / `learning_paths`。每次验收反馈还会回写 `profiles.dims`（`training_rounds` 逐轮证据与 `weak_points` 更新），并写入 `profile_snapshots`、递增画像版本，实现“每学习一轮更新一次画像”。

相关接口：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/workspace/role-context?course_id={id}` | 查询领域、岗位和核心能力映射 |
| `POST` | `/api/workspace/generate` | SSE 执行完整闭环 |
| `GET` | `/api/workspace/runs/{run_id}` | 读取本人运行审计记录 |
| `POST` | `/api/workspace/feedback` | 提交答题证据并更新下一轮策略 |
| `POST` | `/api/workspace/append-quiz` | 在发布后追加题目 |

## 发布门禁

- 事实与来源审核：检查来源是否存在、正文引用编号是否有效、讲义解释是否充分。
- 实操规范审核：检查环境、编号步骤、预期结果、异常处理、安全边界和验收清单。
- 难度与覆盖审核：检查题量、难度层级、诊断难度匹配和岗位核心能力覆盖。
- 总裁决不直接修改内容，只读取审核结果；出现 blocker、审核失败或分数低于门槛时不得发布。

当前审核规则是可复现的结构化规则，便于演示和复核。赛题要求的幻觉率、难度适配准确率和岗位能力点覆盖率仍需在后续真实标注评测集上统计，不能用页面审核分数替代正式实验指标。
