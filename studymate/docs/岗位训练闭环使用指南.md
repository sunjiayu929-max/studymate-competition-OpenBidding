# 岗位训练闭环使用指南

## 功能定位

学习资源工坊以领域与目标岗位执行可审计训练闭环。岗位知识库是检索与数据隔离边界，前端任务、诊断、资源和审核均以目标岗位能力组织。

当前已经接入完整知识库并可运行闭环的是：

- 领域：特定软件开发
- 目标岗位：前线部署工程师（FDE）
- 核心能力：需求澄清、Python 与 SQL、系统集成、客户沟通、交付验证

岗位空间同时展示工业互联网、特定软件开发、人工智能三个领域共九个岗位。除 FDE 外的岗位明确标记为“待建设”；选择会被保存并同步回资源工坊，但在专属知识库接入前不会开放生成按钮，也不会借用无关知识冒充岗位内容。

## 闭环流程

一次运行依次经过：

1. 学情诊断：读取知识基础、薄弱能力点和岗位目标，输出当前水平、目标难度、能力盲区及本轮训练合同。
2. 岗位检索：只在当前目标岗位知识库内检索六个证据片段，作为讲义与实操指南的引用依据；底层 `course_id` 仅承担兼容的数据隔离。
3. 三类生成：定制讲义、实操指南、分阶测试并行生成。
4. 三项审核：事实与来源、实操规范、难度与能力覆盖分别审核，输出分数、指标和纠偏意见。
5. 总裁决：依据结构化审核结果决定发布、定向返工或人工复核。
6. 自动返工：存在发布阻断项时，只退回涉及的讲义、指南或测试，最多自动修订一轮并重新审核。
7. 发布：审核通过后只解锁岗位定制讲义、实操指南和岗位分阶测试；思维导图、拓展阅读、代码案例、学习路径和可视讲解仅保留入口，当前阶段不生成或预取内容。
8. 反馈更新：学习者完成分阶测试后提交真实答题证据，系统给出前置修复、同阶变式或进阶挑战策略，并写回本轮审计记录。

## 前端如何使用

1. 登录后进入“学习资源工坊”。
2. 点击“选择目标岗位”进入岗位空间，依次选择领域和岗位；选定后会自动返回学习资源工坊，并在顶部、侧栏与生成依据中同步显示当前岗位。
3. 输入岗位任务或能力点，例如“完成工业缺陷分类模型的训练与误检分析”。
4. 点击“启动岗位训练闭环”。
5. 在流程板查看当前阶段、八个核心 Agent 状态、诊断盲区、三项审核分数、纠偏条数和裁决结果。
6. 若发生返工，页面会显示返工轮次，生成角色会重新进入运行状态；无需手动重启整轮。
7. 只有显示“批准发布”后，资源卡片才可打开。优先阅读岗位定制讲义和实操指南，再完成岗位分阶测试。
8. 返回工作台，在“学习反馈回写”区域提交答题证据，查看下一轮难度与训练策略。

若第二轮仍有发布阻断项，系统会进入“人工复核”，不会把未通过审核的资源伪装成正式成果。

## 可审计数据

每次运行写入 `training_runs`，保存运行编号、用户、兼容知识库 ID、领域、目标岗位、任务、阶段、生成轮次、诊断、最终资源、三项审核、裁决和反馈。正式资源只在裁决为 `publish` 时写入 `resources` / `learning_paths`。

相关接口：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/workspace/role-context?course_id={id}` | 查询领域、岗位和核心能力映射 |
| `POST` | `/api/workspace/generate` | SSE 执行完整闭环 |
| `GET` | `/api/workspace/runs/{run_id}` | 读取本人运行审计记录 |
| `POST` | `/api/workspace/feedback` | 提交答题证据并更新下一轮策略 |
| `POST` | `/api/workspace/append-quiz` | 在发布后追加题目 |

## 发布门禁

- 事实与来源审核：检查来源是否存在、正文引用编号是否有效、讲义解释是否充分。
- 实操规范审核：检查环境、编号步骤、预期结果、异常处理、安全边界和验收清单。
- 难度与覆盖审核：检查题量、难度层级、诊断难度匹配和岗位核心能力覆盖。
- 总裁决不直接修改内容，只读取审核结果；出现 blocker、审核失败或分数低于门槛时不得发布。

当前审核规则是可复现的结构化规则，便于演示和复核。赛题要求的幻觉率、难度适配准确率和岗位能力点覆盖率仍需在后续真实标注评测集上统计，不能用页面审核分数替代正式实验指标。
