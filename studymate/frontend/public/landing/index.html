01 · What the system actually does

它不是一个 AI，
回答一个问题。它是一套有审核权的训练系统。

系统任务 / Mission

依据学习者证据，生成适合其岗位目标的课程、实操指南与分层测评；再经过独立审核、总裁决与反馈回写，形成可追溯的质量闭环。

02 · One controlled route

一次训练任务，
六段受控航程。

每一个阶段都有明确输入、输出与责任角色。系统不是把提示词串在一起，而是让规划、生产、审核和裁决相互制约。

  1. 证据型诊断

    从测评、履历与行为中识别能力差距，形成学习者画像。

    Diagnosis Agent

  2. 训练规划协商

    领域专家、学习策略与规划仲裁共同定义训练合同。

    3 Planning Agents

  3. 三类资源并发生成

    课程、实操指南与分层测评针对同一目标同步生产。

    3 Production Agents

  4. 三重独立审核

    分别核验事实证据、实操规范、难度与覆盖范围。

    3 Review Agents

  5. 总裁决与返工

    通过则发布；未通过则携带具体意见返回对应环节。

    Arbiter Agent

  6. 反馈写回画像

    学习结果成为下一轮诊断证据，让训练持续收敛。

    Closed Feedback Loop

03 · Multi-agent formation

不是轮流发言。
是分权协同。

生成者不能给自己放行，审核者不能修改原始结论，最终发布权由总裁决统一收口。角色边界让系统可解释、可复核。

04 · Release clearance

未经审核，
不准抵达学习者。

三位审核智能体各自签署质量报告。总裁决读取全部证据，决定发布或定向返工——失败内容不会伪装成正式资源。

05 · Evidence-based personalization

同一岗位，
不是同一条航线。

系统不只改写措辞。它根据能力证据改变前置补齐、内容深度、练习密度与测评层级，让每份训练方案真正发生结构变化。

学习者 A前置知识存在缺口
补前置 → 进阶
学习者 B理论扎实，实操薄弱
强化实操 → 验证
学习者 C已有岗位经验
跳过基础 → 挑战任务

示意：画像证据决定训练结构，而非只改变内容表述。

06 · The loop stays in motion

一次训练结束，
下一轮画像已经更新。

完成度、测评结果与实操反馈被写回学习者画像，成为下一次诊断的新证据。个性化不再是一次推荐，而是持续校准的成长轨道。
