## 2. 当前核查结论

- 后端静态枚举得到 92 个方法-路径操作，折叠同一路径的不同 HTTP 方法后为 78 个唯一路径；接口说明已按代码同步。
- 后端测试目录当前包含 61 个测试方法，使用 Python 3.13 项目依赖环境全部通过；前端 `npm run lint` 与 `npm run build` 已通过。
- 前端时间轴、语音、PPTX、构建预算、阶段 UI、端到端和学习宇宙布局检查全部通过；端到端检查覆盖 5 个竞赛页面、3 个桌面视口，且权限夹具未触发麦克风或全屏申请。
- 工作区结构检查通过（20 个 Markdown、47 条本地链接），种子库重新生成、`gzip -t`、SQLite 完整性/外键检查和 Docker Compose 配置检查均通过；`git diff --check` 通过。
- 真实模型、语音、OCR、邮件和 Piston 的线上能力依赖运行环境配置，本地安全离线模式不代替真实能力验收。

## 3. 已知风险

1. `profile`、`eval`、`workspace` 和 `notes` 的部分接口仍接收请求体或查询参数中的 `user_id`；正式多租户环境上线前必须统一改为从当前会话取用户并校验资源所有权。
2. 课程写操作当前以固定课程返回 `405`，RAG 导入/清空仍是登录级权限；生产环境应收紧为管理员权限并补充审计日志。
3. 数据库结构仍由启动时的轻量迁移维护，长期维护应迁移到正式版本化迁移工具。
4. 外部平台接口可能变化，需继续保留超时、缓存、清洗和稳定搜索入口，并在部署后观察失败率。

## 4. 后续优先级

### P0：交付前

- 完成一条真实账号的端到端走查：登录、选课、画像、资源生成、测验、报告和反馈。
- 在明确预算与运行环境后分别验证模型、语音、OCR、邮件和 Piston 的真实调用。
- 完成生产数据备份恢复演练，确认 HTTPS、Cookie、CORS 和防火墙策略。
- 固化演示录屏路径、讲解顺序和离线降级素材。

### P1：质量增强

- 为认证、课程和完整测验流程补充接口级测试。
- 将用户所有权校验、管理员写权限和数据库迁移纳入独立改造任务。
- 补充真实用户试用证据、统计口径和隐私说明。
