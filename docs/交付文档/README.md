# 软件杯材料提交清单

## 1. “作品源码”压缩包

- StudyMate 完整源代码。
- 保留运行、构建和部署所需的配置示例、依赖清单与维护脚本。
- 不包含真实密钥、本地数据库、日志、缓存、构建产物和其他机器本地状态。

## 2. “作品安装/可执行文件”压缩包

- 可安装、可运行或可直接部署的作品文件。
- 配套的必要运行说明和依赖说明。

## 3. “作品 PPT/演示视频和文档”压缩包

### 演示视频

- 格式不限，时长尽量控制在 7 分钟以内。
- 画面清晰、解说逻辑清楚，系统实际演示占比不低于 60%。
- 清晰展示操作流程、核心功能、多模态资源生成效果和前沿 AI 技术应用成果。

### 演示 PPT

- 展示智能体应用价值、前沿 AI 技术融合思路与实现方法、创新价值和核心功能。
- 至少包含项目背景与系统应用价值、系统架构图、功能结构图、技术栈、核心功能实现、创新点，以及降低资源生成幻觉的方法。
- 内容逻辑清晰、重点突出，图表与页面风格统一。

### 项目文档与数据

- 项目部署文档。
- 系统部署说明书。
- 系统开发说明书。
- 测试说明书。
- 系统设计说明书：至少包括系统架构图、功能结构图、技术栈、功能实现和创新点，并包含完整的个性化学习场景全流程案例、验证结果及系统效果截图。
- 测试知识库数据集。
- AI Coding 使用说明；使用 AI Coding 工具时说明使用方式及其在项目开发中的作用。

项目文档需清晰说明前沿 AI 技术的应用细节，并至少覆盖以下内容：

- 需求层面：分析新时代大学生的学习需求和前沿 AI 技术应用场景，明确技术与需求的结合点。
- 技术开发层面：说明智能体设计、开发、测试和部署全流程，包括界面设计、功能实现、系统集成与优化。
- 重点说明前沿 AI 技术的融合思路、实现方法、创新实践和用户体验提升策略。
- 使用充分的数据、案例、图表、流程图和架构图增强可读性与说服力，并保持文档格式统一。

当前《项目部署文档》和《系统部署说明书》由 `生成脚本/generate_docs.py` 统一生成。正文按内容自然分页，目录页码随最终 PDF 自动更新，不再为了固定页数保留大面积空白或缩小整页内容。

## 4. “报名表和学生证”压缩包

- 赛事报名表。
- 参赛学生的学生证材料。
