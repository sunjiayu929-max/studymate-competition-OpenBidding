# StudyMate 文档总索引

`docs/` 保存竞赛来源材料、当前开发计划、参考资料和最终交付文档；应用的当前技术文档位于 [`../studymate/docs/`](../studymate/docs/)。

## 目录说明

| 目录 | 内容 | 维护方式 |
| --- | --- | --- |
| [`赛事相关/`](赛事相关/) | 软件杯、挑战杯赛题与参赛材料 | 作为权威来源保留，不改写原文 |
| [`参考资料/`](参考资料/) | 外部部署文档示例 | 仅供版式与内容范围参考，不视为本项目现状 |
| [`项目开发相关/`](项目开发相关/) | 当前开发计划 | 只保留仍对当前开发有用的结论 |
| [`交付文档/`](交付文档/) | 软件杯材料提交清单、部署交付文件及其生成脚本 | 交付文件放 `交付文件/`，生成源码与素材放 `生成脚本/` |

## 文档边界

- `README.md`、`studymate/docs/` 和 `项目开发相关/plan.md` 描述当前事实。
- 阶段交接、会话记录与累计开发日志不作为现行文档维护；需要追溯的过程使用 Git 历史。
- PDF、DOCX、HTML 赛题和外部参考文件属于来源材料；本次只核对归档位置与索引，不修改其权威正文。
- `赛事相关/derived/` 是从来源材料提取的可检索文本，可重新生成，但不能替代原文件。
